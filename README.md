# Danfolio Logistics

Campus keke booking app. React + JavaScript + Supabase, deployed on Vercel.

## First-time setup
1. Copy `.env.example` to `.env.local` and fill in your Supabase URL and publishable key.
2. `npm install`
3. `npm run dev` and open the link it prints.

## Folders
- `src/student` student app
- `src/keke` keke rider app
- `src/admin` admin pages
- `src/lib` Supabase client and sign-in helpers

Never commit `.env.local` or any secret/service_role key.
